The Solution

Existing cameras → a real-time operations brain.

RetailEdge AI plugs into the CCTV stores already have and runs every model locally on a Qualcomm edge node. Four capability pillars, mapped 1:1 to the problem statement:

🚶

Shopper Analytics

Entry/exit counting, footfall by hour & zone, dwell time, live heatmaps — all anonymous.

📦

Inventory Vision

Shelf cams detect low / out-of-stock & planogram drift, then auto-dispatch restock tasks.

🧾

Queue Intelligence

Per-counter queues, wait & service times, and congestion predicted before it hits.

⚡

Edge + Privacy

All inference on-device, offline-first, no PII — metadata-only uplink, DPDP-aligned.

No new cameras. No cloud dependency. No PII. Actionable insight in <60 seconds.

How It Works

Offline-first. Hybrid by choice, not by need.

01 · SENSE

Camera Layer

  • Existing IP/CCTV — no rip & replace
  • Shelf-facing cams for SKU vision
  • On-prem RTSP ingest · PoE
➜
02 · INFER — ON DEVICE

Edge Node · QCS6490

  • Hexagon™ NPU via QNN
  • INT8 models from Qualcomm AI Hub
  • YOLOv8n + ByteTrack · SKU detector
  • Tripwire · dwell · heatmap · planogram
  • Queue forecaster (GBM time-series)
  • 30 FPS @ ~8 ms · <10 W
➜
03 · ACT — IN STORE

Edge Gateway

  • MQTT event bus · local DB
  • Dashboard on LAN · staff alerts
  • POS / ERP connectors
  • Auto-dispatch replenishment
➜
04 · SYNC — OPTIONAL

Cloud Plane

  • Multi-store federation
  • Fleet OTA model updates
  • ~15 MB/day metadata only
  • Store runs 100% without it
